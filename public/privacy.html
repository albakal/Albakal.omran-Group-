سياسة الخصوصية وحماية البيانات

تاريخ السريان: أكتوبر 2026 | مجموعة عمران (Albakal Omran Group)

أهلاً بكم في تطبيق البقال. نولي خصوصية بياناتكم وأمان معلوماتكم الشخصية أهمية قصوى. تهدف هذه الوثيقة إلى توضيح نوعية البيانات التي يتم جمعها وكيفية معالجتها وحمايتها عند استخدامكم لتطبيق البقال أو خدماتنا المرتبطة.

1. المعلومات التي نجمعها

نقوم بجمع الحد الأدنى من المعلومات اللازمة لتقديم الخدمات اللوجستية والتجارية بدقة:

  • بيانات الحساب: الاسم، رقم الهاتف، نوع الحساب (عميل، تاجر، كابتن توصيل).
  • الموقع الجغرافي والمنطقة: المحافظة والمنطقة السكنية التابع لها العميل أو التاجر أو الكابتن، لضمان حصر الطلبات وتوصيلها بدقة في نفس النطاق الجغرافي المعتمد.
  • بيانات الطلبات والسلة: المنتجات المختارة، عنوان التسليم، وتفاصيل الطرد.

2. الغرض من استخدام البيانات

  • ربط العملاء بالمتاجر المحلية المعتمدة داخل نفس المنطقة السكنية.
  • تمكين التجار من إسناد وتوجيه الطرود لكباتن التوصيل المحليين عبر رسائل منظمة.
  • متابعة حالة الطلبات والفواتير الإلكترونية وسجل المديونيات.
  • تحسين تجربة الاستخدام وضمان كفاءة وأمان منصة البقال.

3. مشاركة وحماية البيانات

نحن لا نبيع أو نؤجر أو نشارك بياناتكم الشخصية مع أي طرف ثالث لأغراض تسويقية أو دعائية. يتم تبادل معلومات الطلب الضرورية (اسم العميل، العنوان، رقم الهاتف، والسلع) حصرياً بين التاجر وكابتن التوصيل المسؤول عن تنفيذ وتسليم الشحنة فقط.

4. تخزين وأمان البيانات

تُخزن البيانات وفق بروتوكولات حماية وتشفير قياسية عبر خدمات Google Firebase السحابية، مع تطبيق معايير أمان مشددة تمنع الوصول غير المصرح به.

5. حقوق المستخدم وإدارة الحساب

يحق لأي مستخدم (عميل أو تاجر أو كابتن) مراجعة بياناته، تعديلها، أو طلب حذف حسابه وسجلاته في أي وقت عبر التواصل المباشر مع إدارة المنصة.

6. التواصل والاستفسارات

إذا كان لديكم أي استفسار بخصوص سياسة الخصوصية أو إدارة بياناتكم، يسعدنا تواصلكم عبر البريد الإلكتروني:
support@albakal.app أو عبر واتساب الدعم الفني لمجموعة عمران.
