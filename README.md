# متجر Play | Play Store Web

تطبيق متجر تطبيقات وألعاب متكامل بتصميم وهوية **Google Play** الرسمية، يتيح لأي شخص تجربة، تحميل، ورفع التطبيقات والألعاب مع استخراج تلقائي للأيقونات والصور وربط حساب Google (Gmail).

## 🌟 الميزات الرئيسية:
- **هوية متجر Play**: شعار Google Play الرسمي مع وضع ليلي ونهاري وخطوط عربية حديثة (Cairo).
- **رفع التطبيقات والألعاب**: رفع ملفات الـ APK مع فحص الحزمة واستخراج الأيقونة والصور تلقائياً مثل Google Play Console.
- **تسجيل الدخول بحساب Google**: دعم تسجيل الدخول بحساب Gmail (`modm55085@gmail.com`) للتحقق من هوية المطورين.
- **تشغيل الألعاب فوري في المتصفح**: تجربة ألعاب الأركيد والرالي وتطبيقات الأذكار ومحرر الأكواد دون تثبيت.
- **تنزيل حقيقي وتثبيت**: زر تنزيل حقيقي مع شريط تقدم ومحاكاة تثبيت واقعية.
- **تقييمات ومراجعات**: نظام تقييم بالنجوم وإضافة تعليقات المراجعين مع تحديث فوري للمعدل.

## 🌐 تفعيل استضافة GitHub Pages مجاناً:
1. اذهب إلى إعدادات المستودع **Settings** في GitHub.
2. اختر **Pages** من القائمة الجانبية.
3. في قسم **Build and deployment**:
   - يمكنك اختيار **Deploy from a branch** واختيار فرع `main` ومجلد `/docs`.
   - أو اختيار **GitHub Actions** ليتم النشر التلقائي عبر ملف الـ Workflow المرفق.
